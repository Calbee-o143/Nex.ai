# Nex.AI

A chat app in one HTML file. No server, no build step, no install. Open it in a browser, paste an API key, and start chatting.

## Features

- **Bring your own key.** The provider is detected from the key. It supports OpenAI, Anthropic (Claude), Google Gemini, Groq, OpenRouter, xAI, Mistral, DeepSeek, Perplexity and others, with a step-by-step guide for getting a key from each.
- **Any OpenAI-compatible service.** A Custom URL option with a "Test connection" button works out which address and key format a service uses. It covers smaller providers and local servers like Ollama.
- **Chrome-style tabs.** Each tab is its own chat with its own key and AI, and past chats are saved.
- **Per-chat AI switcher.** Change the model, or move a chat to another saved key, without losing the conversation.
- **Code sandbox.** HTML, SVG and JavaScript in replies get Code, Preview and Split views, running in an isolated iframe.
- **Attachments, voice and screen sharing.** Send images and text or code files, dictate messages, or share your screen with a vision-capable model.
- **Image generation** with an OpenAI key.
- **Light and dark themes**, a custom name for the AI to call you, and mobile-friendly layout.

## Privacy

Everything runs in your browser. Chats and API keys are stored in your browser's localStorage and are sent only to the AI provider you choose. There is no backend and no analytics.

## Usage

1. Download `index.html` and open it in a browser.
2. Pick your AI provider and follow the key guide, or paste a key you already have.
3. Start chatting.

## Notes

- Some providers block requests made directly from a web page (CORS). Those can't be used from a browser-only app.
- Screen sharing and image understanding need a model that supports images.
